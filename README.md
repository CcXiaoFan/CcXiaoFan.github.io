# Xiaofan Cui — Academic Portfolio

Static research portfolio for GitHub Pages. The site uses plain HTML and CSS with no build step.

## Publish with GitHub Pages

1. Create a public repository named `CcXiaoFan.github.io`.
2. Push the contents of this folder to the repository's `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`.

The site will be available at `https://ccxiaofan.github.io`.
