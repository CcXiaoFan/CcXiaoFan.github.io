Adaptive User Modeling for Uncertain Interaction

A closed-loop personal-agent testbed that learns from explanation requests, acceptance, rejection, and corrections.

The system treats acting, explaining, clarifying, offering alternatives, and returning control as distinct decisions. It records interaction feedback, updates individual preference profiles, and adapts subsequent explanation decisions. Technical validation is complete; a formal user study is in preparation.
