01 / Research focus

The question

How should an adaptive system respond when it is not sure what a person means?

My work connects uncertainty-aware interaction, individual user modeling, and adaptive decision-making. I use smart environments as a controllable testbed for studying how an agent can learn preferences without hiding uncertainty or taking control away from the user.

Ambiguous request→Intent candidates→Interaction strategy→User feedback→Updated user model

WORKING PROTOTYPE · UE5 SIMULATION
01

Master's thesis · 2026–present

Adaptive User Modeling for Uncertain Interaction

A closed-loop personal-agent testbed that learns from explanation requests, acceptance, rejection, and corrections.

  • Persistent individual preference profiles
  • Adaptive explanation decisions across interactions
  • Multi-agent workflow connected to a controllable UE5 environment
  • Technical validation complete; formal user study in preparation
Read the research logic +

The system represents multiple plausible interpretations of an ambiguous request and treats acting, explaining, clarifying, offering alternatives, and returning control as distinct choices. Feedback from each interaction updates the individual model used in later decisions.

02

Empirical study · 211 valid participants

Explainable Responses under Ambiguous Intent

An experiment on how request ambiguity and response explainability jointly shape experience with LLM-based smart-home assistants.

  • Outcomes: trust, satisfaction, and enjoyment
  • Greater explainability mitigated the adverse effects of ambiguity
  • First-author manuscript revised following second-round peer review
